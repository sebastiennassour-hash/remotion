## Refaire un rendu

```bash
cd vision-agency
npm i
./fetch-clips.sh                 # récupère les 12 plans
npx tsx render.mts --prefix=VR-  # les 10 reels
npx tsx render.mts               # les 15 posts
```

Pour changer un texte : `src/reels/reels.ts` (reels) ou `src/posts.ts` (posts), puis relancer.
