# CRM — une fiche par restaurant, classée par ville

Règle (CERVEAU.md, étape 13) : toute information que Nassour donne sur un prospect ou un client est posée dans sa fiche ici dans les 10 minutes, datée, avec la prochaine étape. La fiche est la mémoire ; ClickUp Pipeline porte le statut ; Vision OS porte le suivi commercial.

- `crm/<ville>/<restaurant>.md` : identité, échanges datés, ses mots, objections, objectif pressenti, prochaine étape, transcriptions.
- Enregistrements : Drive › 02-Prospection › Appels › Enregistrements, nommés `AAAA-MM-JJ_<restaurant>.m4a`. Claude transcrit (faster-whisper) et colle la transcription dans la fiche. Sans enregistrement : débrief vocal ou écrit de Nassour en sortant, Claude le classe.
- Le dépôt est tiré sur le Mac chaque matin à 06h30 (~/VISION/07-Process/vision-agency/crm).
- Jamais de prix dans une fiche, jamais de chiffre de résultat non prouvé, rien pour l'ex-client de Fribourg.
